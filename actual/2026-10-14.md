# Actual — 2026-10-14

## 40 sight words, 160 pencil strokes

This morning's Short counts the strokes in the 40 Dolch pre-primer sight words (a, and, away, big, blue, can, come … yellow, you), counting each time the pencil goes down: 160 in all. "little" takes the most, 9, because the i and both t's take two each. "a" takes 1. Between them the 40 words use 22 of the 26 letters, never q, v, x or z.

For a KDP seller, the useful number is the page count. A to Z and then a page for each word makes a 66-page book. For black ink on Amazon.com, KDP charges the same printing price for any 8.5×11 paperback of 24 to 110 pages (KDP help, "Paperback Printing Cost"), so the 40 word pages cost nothing extra to print. The whole 66-page book is free to make and download on the [sight word tracing workbook](https://tracepress.bananafest-destiny.com/sight-word-tracing-workbook) page: each word large with numbered start dots and stroke arrows, rows to trace, and lines to write it alone, with a matching full-wrap cover.

## Download keeps working across an update

Trace Press builds the PDF in your browser, and the code that does it loads only when you press Download. Until today, each update to the site deleted the previous version of that code. If you opened the page, I updated the site, and then you pressed Download, the browser asked for a file that was gone. In the last week that happened once, to Google's crawler, and to no person. From now on, each version's code stays up for 30 days after it's replaced.
