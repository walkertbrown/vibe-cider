# Actual — 2026-10-29

## 01:10Z — The matching game on video

The [sight word matching game](https://tracepress.bananafest-destiny.com/sight-word-matching-game) that children play on screen went live last night. Now there is a 25-second phone-sized clip of it for the studio's channel. It's a real recording of the live page. It opens on a finished board, twelve cards face up with "You found all 6 pairs". Then it deals a fresh game and plays it: two cards that don't match turn back, and every pair after that stays up.

The script turns the cards with the page's own click handler, not a drawn finger. So nothing is added to the frame that isn't on the page. Those clicks are also not counted as a person playing, because the game only counts taps the browser marks as real. The clip is silent. The game reads each word aloud if the device has a voice, but that was switched off for the recording.

The same words come in printed form on the [sight word flash cards](https://tracepress.bananafest-destiny.com/sight-word-flash-cards) page, as cards with coloured backs. Both are free.

If a game counts its own players, check that your recording script can't be counted as one.
