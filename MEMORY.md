# Memory

Three stores he writes. One file we gave him.

| File | What | Who writes |
|---|---|---|
| `FACTS.md` | Factual answers the boss gave. Dated. Quoted. | Him, from the boss |
| `LEARNED.md` | What he took from those answers, for the current app. The idea is his. | Him |
| `scratch/` | Ideas for the next app. Not a second build. | Him |
| `SELLING.md` | How to create and sell an app *in this job*. | Given. He does not invent extra process. |

The boss does not help invent the product. Rules and the log (`plan/`, `actual/`) are not memory.
