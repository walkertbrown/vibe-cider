# Memory

Three stores he writes. One file we gave him.

| File | What | Who writes |
|---|---|---|
| `FACTS.md` | What the boss said in conversation. Dated. Quoted. | Him, from the boss |
| `LEARNED.md` | What he took from that for the current app. Quotes vs inference, labeled. | Him |
| `scratch/` | Ideas for the next app. Not a second build. | Him |
| `SELLING.md` | How to create and sell an app *in this job*. | Given. He does not invent extra process. |

Rules and the log (`plan/`, `actual/`) are not memory.
