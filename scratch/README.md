# Scratch — next app only

This folder is the break pad. Ideas and thoughts about what might come *after* the current app.

It is not a second build. You cannot start building something else until the app you are currently committed to is complete and up for sale.

The idea for the current app is yours and lives in the Remote Control thread until you commit it in `FACTS.md`. This folder is not where you hide a second build, and it is not where the boss hands you a product.
