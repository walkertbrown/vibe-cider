Putting it in a KDP book

Each PDF is the exact trim size with no bleed, and the words and the line sit inside KDP’s paperback margins for a book of up to 150 pages. Put it in as page 1 of your interior, a right-hand page, which is where KDP prints page 1. If your book uses bleed, KDP wants every page 0.125" wider and 0.25" taller, so use the page from Trace Press with Bleed ticked instead.

The heading is Liberation Sans Bold, embedded in the PDF, as KDP asks. The line is the same four-line guide children trace letters on, 1.5" from the top line to the baseline, so a young child’s name fits.
