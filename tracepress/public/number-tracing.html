Free number tracing worksheets, 0 to 9

Ten printable pages, one for each digit. Each page shows the number large, with a green dot numbered for where each stroke starts and a red arrow for the way it goes. Below that are rows of the number in dots to trace, then rows with one dotted number and room to write it alone.

Download the worksheets (PDF, 10 pages)

8.5" × 11", about 75 KB. The lines are 1" from top to bottom, the Trace Press setting for ages 4–5. No sign-up. A small footer line on each page says where it came from.

How each number is written

The start dots and arrows follow a published school number formation chart. A school's number rhymes describe the same strokes for all ten digits.

Numbers in a tracing book for KDP

The same ten pages can go into an A–Z letter tracing workbook you publish on Amazon KDP. Open Trace Press with Numbers 0–9 ticked and the book is the 26 letter pages, then 0 to 9: 36 pages, with a full-wrap cover sized to match. You can add practice words after the numbers too, up to 42 of them.

For black ink on Amazon.com, KDP charges one flat printing price for any paperback of 24 to 110 pages, so the number pages add nothing to the printing cost: $2.84 a copy at 8.5" × 11". The handwriting workbook guide has the full price table.
