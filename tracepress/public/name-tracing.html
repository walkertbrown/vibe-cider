Name tracing worksheet, as a free PDF

Type a name. The sheet shows it large at the top, with a numbered green dot where each stroke starts and a red arrow for the way it goes. Below that are rows of the name in dots to trace, and empty lines at the bottom to write it without help. Print it at home. It's free, with no sign-up, and the name never leaves your browser.

The height from the top line to the baseline. Bigger lines are for younger hands. A long name gets smaller letters so it fits across the page.

For printing at home, 8.5" × 11" is US Letter.

What's on the sheet

One page. The name once, big, with start dots and arrows on every letter, in the same print letters as the Trace Press workbook. Then the name in dotted letters, repeated across each row as many times as it fits. The last rows are blank four-line guides: a solid top line, a dashed midline, a solid baseline and a dotted line for tails.

Letters it draws

Capitals A–Z, lowercase a–z and the numbers 0–9, up to 16 characters and spaces. Accented letters, hyphens and apostrophes aren't drawn yet, so "Mary-Kate" comes out as "MaryKate". The note under the name box says when something was left out.
